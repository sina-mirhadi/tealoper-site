# TeaLoper — سایت سینا میرهادی

## نصب و اجرای محلی
```bash
npm install
npm run dev
```

## ساخت نسخه‌ی نهایی برای هاست
```bash
npm run build
```
خروجی در پوشه‌ی `dist` است. کل این پوشه را روی هاست آپلود کن.
(بیلد، برای هر صفحه یک HTML سئو‌شده می‌سازد و sitemap و robots را هم تولید می‌کند.)

## قبل از دیپلوی (حتماً)
1. دامنه‌ی واقعی‌ات را در `src/data/site.json` بخش `siteUrl` بگذار. بدون این، canonical و sitemap درست نیستند.
2. در `index.html` عنوان و توضیحات پیش‌فرض را در صورت نیاز ویرایش کن.
3. یک تصویر OG (1200×630) در `public/og.png` بگذار و در `scripts/prerender.mjs` به متا اضافه کن.
4. در Google Search Console دامنه را ثبت و sitemap.xml را ارسال کن.
5. (اختیاری) برای فرم تماس یک سرویس دریافت فرم بساز و آدرس را در `.env` با نام `VITE_CONTACT_ENDPOINT` بگذار. اگر خالی باشد، فرم پیام را به تلگرام می‌فرستد.

## هاست‌ها
- **Apache (cPanel و غیره):** فایل `.htaccess` در `public` همراه بیلد می‌رود و برای مسیرهای SPA لازم است.
- **Netlify / Cloudflare Pages:** فایل `_redirects` در `public` همراه بیلد می‌رود.
- **Nginx:** این قاعده را اضافه کن: `try_files $uri $uri/ /index.html;`

## ویرایش محتوا
- همه‌ی متن‌ها، مهارت‌ها، خدمات، پرسش‌های متداول، نوشته‌ها و پروژه‌ها در `src/data/site.json` هستند.
- پنل `/admin` فقط JSON پروژه‌ها را می‌سازد؛ همیشه بعدش در `site.json` ذخیره و دوباره بیلد کن.

## یادداشت امنیتی
پنل `/admin` سمت کلاینت است و امنیت سرور ندارد. اگر آن را لازم نداری، فایل `src/admin/Admin.jsx` و مسیر `/admin` را از `App.jsx` حذف کن.
